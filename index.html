Tentang RupiahLens v4.0

RupiahLens v4.0 adalah aplikasi identifikasi pecahan uang Rupiah berbasis AI yang berjalan sepenuhnya di browser menggunakan TensorFlow.js.

Model AI dilatih menggunakan Google Teachable Machine. Class yang didukung:

✅ 1 Ribu   ✅ 2 Ribu   ✅ 5 Ribu   ✅ 10 Ribu
✅ 20 Ribu   ✅ 50 Ribu   ✅ 75 Ribu ⭐ NEW   ✅ 100 Ribu
✅ Background (bukan uang / latar belakang)
🆕 v4.0: Tambah 75 Ribu · Deskripsi lengkap · Konverter multi-valuta
🎓 Tugas: Machine Learning — Image Classification
🔧 Stack: Teachable Machine + TensorFlow.js
🔒 Data: Diproses 100% lokal di browser Anda

Untuk deploy: ganti variabel _M dengan URL model Teachable Machine Anda, lalu upload ke GitHub Pages / Netlify / Vercel.
